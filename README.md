# Frontier Trail™

A trail game for the Great Commission. Lead a team toward multiplying
churches among a frontier people, one hard decision at a time.
30 to 60 minutes, one player or one room.

**Play:** https://4thenations.com/frontier-trail

## Translate it
1. Click **Fork** (top right).
2. Translate the player-facing text in `index.html`.
3. Open a pull request, or email for name approval (see `TRADEMARK.md`).
   Approved translations publish as "Frontier Trail (Language)."
